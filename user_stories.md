User Stories

Customer

As a customer, I want to create an order so that I can purchase products online.

As a customer, I want to pay for my order so that my purchase can be processed.

As a customer, I want to track my order status so that I know when it will be delivered.

As a customer, I want to cancel an order before shipment so that I can change my purchase decision.

As a customer, I want to receive notifications about order updates so that I stay informed.


Support Agent

As a support agent, I want to search customer orders so that I can resolve customer requests.

As a support agent, I want to update order information so that order issues can be corrected.



Warehouse Operator

As a warehouse operator, I want to view orders awaiting fulfillment so that I can prepare shipments.

As a warehouse operator, I want to update shipment status so that customers receive accurate tracking information.



Administrator

As an administrator, I want to manage users and permissions so that access to the system remains secure.

As an administrator, I want to view all orders and system activity so that business operations can be monitored.
