E-commerce Order Management System (OMS)

Overview

This project is a Product & System Design case study of an E-commerce Order Management System (OMS).
It demonstrates end-to-end order lifecycle design, product thinking, and system architecture.

⸻

Key Features

* Order lifecycle management
* Payment processing flow
* Warehouse processing logic
* Delivery and return flows
* Role-based system design

⸻

System Components

* Orders
* Users
* Payments
* Shipments

⸻

Process Flow

Created → Paid → Processing → Shipped → Delivered

Includes alternative flows:

* Cancel order (before shipment)
* Return order (after delivery)
* Payment failure handling

⸻

Artifacts in this project

* User Stories
* Product Metrics
* Order Lifecycle
* ERD / Database schema
* REST API (OpenAPI)
* BPMN-style process flow

⸻

Purpose

This project demonstrates product analytics, business analysis, and system design skills for e-commerce systems.
